EstateFlow

Gestión inteligente de comunidades residenciales

Plataforma SaaS que digitaliza y centraliza la operativa de urbanizaciones: incidencias, reservas, paquetería, accesos, obras y notificaciones.

Django 5 React 19 TypeScript Tailwind CSS v4

Proyecto Final — Máster en Desarrollo Full Stack

El problema

La mayoría de comunidades residenciales gestionan su operativa mediante:

  • Grupos de WhatsApp desordenados
  • Papel y cuadernos de notas
  • Hojas de cálculo sin control de acceso
  • Llamadas telefónicas para reportar incidencias

Esto genera pérdida de información, falta de trazabilidad y procesos lentos.

La solución

EstateFlow centraliza toda la operativa en una plataforma digital con:

📋 Incidencias

Reporte y seguimiento con máquina de estados y trazabilidad completa.

📅 Reservas

Reserva de instalaciones comunes con validación de disponibilidad.

📦 Paquetería

Control de recepción y entrega de paquetes en tiempo real.

🔐 Accesos

Autorización de visitas y proveedores de forma segura.

🏗️ Obras

Registro de obras para autorizar accesos de empresas.

📊 KPIs

Panel de control con tiempos de resolución e incidencias abiertas.

Tecnologías

Backend

  • Python 3.12 + Django 5
  • Django REST Framework
  • SimpleJWT (autenticación)
  • SQLite / PostgreSQL
  • Desplegado en Render

Frontend

  • React 19 + TypeScript
  • Vite 8
  • Tailwind CSS v4
  • Framer Motion
  • GitHub Pages + CI/CD

Roles de usuario

👑 ADMIN

Gestión global: usuarios, métricas, KPIs, incidencias críticas. Acceso a todo el sistema.

🔧 STAFF

Operativa diaria: gestionar incidencias, registrar paquetes, controlar accesos.

👤 USER

Residente: reportar incidencias, reservar instalaciones, autorizar visitas, registrar obras.

Cada rol tiene vistas y permisos diferenciados tanto en la API como en el frontend.

Integración React + Backend

  • Autenticación JWT (access + refresh tokens)
  • Peticiones autenticadas con Bearer token
  • Renovación automática del token al expirar
  • Componentes reutilizables con Tailwind CSS
  • Animaciones con Framer Motion
  • Routing protegido por rol (RoleGuard + ProtectedRoute)

El frontend hace peticiones reales al backend Django y renderiza los datos en tiempo real.
